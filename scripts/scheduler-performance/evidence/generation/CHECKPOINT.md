# Monthly generation and mobile sheet checkpoint

This increment adds a bounded local monthly generator and separates phone day inspection into an accessible modal sheet. It is still a fictional, in-memory preview, never a published schedule. No production source, database, credentials, access permissions or formal writer claims are changed. The existing security, CSV normalization and excluded-assignment audit corrections remain in place.

## Verification ledger

- Initial generation implementation: 1,062 unit tests passed; production and isolated preview builds passed. Both engines passed three layouts (1440 px normal text, 390 px normal text, 320 px at 200% text), plus worker failure, cancellation and Escape/focus checks. Eighteen scoped WCAG A/AA axe scans passed. `generator-baseline-results.json` retains those results before the later modal sheet change.
- Twenty Generate-click to usable-proposal measurements per engine, 100 fictional people, 31 days, mixed mode, one exact opening-shift template, minimum two people and one sales-role holder. Chromium p95 1,810 ms; WebKit p95 1,461 ms, nearest-rank p95. All raw samples are retained. Question time is excluded; input snapshot, worker startup, compute, render and two animation frames are included. This meets the 30-second target for this local synthetic envelope only, not arbitrary policies or physical devices.
- The first sheet attempt failed Chromium's repeated Tab focus-containment assertion after its desktop case passed. `sheet-first-attempt.json` preserves the completed case. Explicit first/last-control wrapping corrects that issue. The original run is not a pass.
- Initial probe setup failures were harness errors: inline axe loading was blocked by CSP, then a route override omitted JavaScript MIME type. The probe uses same-origin routed axe and preserves CSP; neither failure is counted as application validation.

Final sheet, Delivered preservation, literal-name regression, final full tests, exact remote/CI and protected deployment verification are recorded below when completed.
